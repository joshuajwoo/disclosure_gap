# Privacy and security controls

These documents define the security boundary for the synthetic portfolio system and the additional controls required before any real-participant deployment. A checked review task means the review was performed; it does not mean the real-data gate passed.

- `threat-model.md`: assets, actors, trust boundaries, abuse cases, and mitigations.
- `logging-policy.md`: event allowlist and prohibited log content.
- `secrets-and-environments.md`: environment separation, credentials, and configuration gates.
- `retention-and-deletion.md`: lifecycle, withdrawal, tombstones, backups, and verification.
- `restricted-exports.md`: manual export authorization, data minimization, and audit records.
- `pre-deployment-review.md`: current control evidence and unresolved real-data blockers.
