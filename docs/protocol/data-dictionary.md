# Protocol data dictionary

Status: draft 0.1.0. Exact storage names and constraints will be finalized in `packages/contracts` and the relational schema.

| Domain / field                   | Type / values                                                                           | Missing semantics                                                | Sensitivity and retention                                                  |
| -------------------------------- | --------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | -------------------------------------------------------------------------- |
| participant_id                   | random UUID/opaque ID                                                                   | never null after creation                                        | Pseudonymous link key; restricted; delete per approved policy.             |
| age_band                         | `18_19`, `20_22`                                                                        | ineligible/nonresponse is not stored as an enrolled participant  | Sensitive eligibility data; no exact age/DOB.                              |
| created_at                       | UTC timestamp                                                                           | never null                                                       | Operational; restricted.                                                   |
| withdrawal_state                 | active/withdrawal_requested/deleted                                                     | never null                                                       | Lifecycle control.                                                         |
| consent_version                  | immutable semantic version                                                              | never null for enrollment                                        | Compliance record.                                                         |
| consent_action                   | agree/withdraw                                                                          | never null                                                       | Compliance record; retention determined by institution.                    |
| consent_at                       | UTC timestamp                                                                           | never null                                                       | Compliance record.                                                         |
| assessment_type                  | baseline/follow_up                                                                      | never null                                                       | Research data.                                                             |
| instrument_name/version/language | `apa_dsm5tr_sad_adult` / `DSM-5-TR-2022` / `en`                                         | never null                                                       | Versioned outcome identity; official wording remains normative.            |
| instrument_item_response         | `SAD01`–`SAD10`; integer 0–4                                                            | explicit `prefer_not_to_answer`; null means absent/not submitted | Sensitive mental-health-related response.                                  |
| instrument_total                 | integer 0–40; raw or officially prorated                                                | null with 3 or more unanswered items                             | Derived sensitive response; never show diagnostic/severity label.          |
| assessment_completed_at          | UTC timestamp                                                                           | null until complete                                              | Establishes temporal ordering.                                             |
| check_in_week                    | integer 1–4                                                                             | never null                                                       | Unique with participant.                                                   |
| wanted_to_share                  | yes/no/not_sure/prefer_not_to_answer                                                    | null means unanswered/incomplete                                 | Predictor source. Only yes enters primary denominator.                     |
| intended_audience                | friend/family/partner/other_trusted/no_particular_person/prefer_not_to_answer           | null or N/A when skipped                                         | Potentially sensitive context.                                             |
| sharing_action                   | shared/not_shared/chose_private/no_safe_opportunity/not_applicable/prefer_not_to_answer | null or N/A when skipped                                         | Preserve raw category; never equate privacy or missingness with pathology. |
| expected_comfort                 | ordinal 1–5/not_applicable/prefer_not_to_answer                                         | null or N/A when skipped                                         | Sensitive predictor.                                                       |
| anticipated_judgment             | yes/no/shared_as_wanted/not_applicable/prefer_not_to_answer                             | null or N/A when skipped                                         | High overlap risk; secondary only.                                         |
| support_confidence               | ordinal 1–5/not_applicable/prefer_not_to_answer                                         | null or N/A when skipped                                         | Sensitive predictor.                                                       |
| concern_category                 | everyday/personal_insecurity/other/prefer_not_to_answer                                 | null or N/A when skipped                                         | No free text.                                                              |
| check_in_completed_at            | UTC timestamp                                                                           | null until complete                                              | Follow-up cutoff enforcement.                                              |
| baseline_support                 | ordinal 1–5/no_person/prefer_not_to_answer                                              | null means unanswered                                            | Prespecified context variable.                                             |
| baseline_everyday_comfort        | ordinal 1–5/not_applicable/prefer_not_to_answer                                         | null means unanswered                                            | Secondary feature source.                                                  |
| baseline_insecurity_comfort      | ordinal 1–5/not_applicable/prefer_not_to_answer                                         | null means unanswered                                            | Secondary feature source.                                                  |
| study_event_type                 | strict allowlist                                                                        | never null                                                       | No response bodies, tokens, or free text. Short operational retention.     |
| study_event_at                   | UTC timestamp                                                                           | never null                                                       | Operational.                                                               |
| recovery_code_hash               | password-hash string                                                                    | null after deletion                                              | Authentication secret verifier; never export.                              |

## Derived variables

| Field                             | Definition                                                                                                                                     | Undefined/missing rule                                                                      |
| --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| intention_action_gap              | count of eligible wanted=yes weeks with action not_shared or chose_private / count of eligible wanted=yes weeks with classifiable share action | Missing when denominator is zero; safety/opportunity, N/A, preference nonresponse excluded. |
| audience_asymmetry                | mean eligible comfort for friend minus mean for family                                                                                         | Missing unless both audiences have observations.                                            |
| topic_sensitivity_gap             | baseline everyday comfort minus personal-insecurity comfort                                                                                    | Missing if either is nonnumeric.                                                            |
| anticipated_judgment_rate         | judgment=yes / check-ins with applicable yes/no judgment response                                                                              | Missing at zero denominator; secondary/leakage-sensitive.                                   |
| support_mismatch_rate             | wanted=yes with low support confidence / wanted=yes with numeric support confidence                                                            | Threshold frozen before outcomes; missing at zero denominator.                              |
| within_person_comfort_variability | prespecified sample SD of numeric weekly comfort                                                                                               | Missing with fewer than two numeric observations.                                           |

Every export must carry schema, survey, feature, and export versions. Source responses remain immutable; corrections append an auditable version under an approved procedure.
