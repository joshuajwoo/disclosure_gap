# Resume Draft — The Disclosure Gap

## Project title

**The Disclosure Gap | Longitudinal Social Anxiety Research Platform**

## One-line description

Research-oriented web and data platform studying whether gaps between wanting to share personal concerns and actually sharing them are associated with social anxiety among young adults ages 18–22.

## Tools and technologies

Python, TypeScript, React, Next.js, FastAPI, PostgreSQL, SQLAlchemy, Alembic, Polars, DuckDB, statsmodels, scikit-learn, Docker, pytest, Playwright, GitHub Actions.

## Resume bullets — adapt after implementation

- Built a privacy-conscious Next.js and FastAPI study platform for consent, weekly structured check-ins, participant-owned trend views, and data deletion, backed by PostgreSQL.
- Engineered reproducible Python features capturing disclosure intention–action gaps, audience asymmetry, and topic-specific sharing comfort across repeated check-ins.
- Evaluated the association between engineered disclosure features and follow-up social anxiety scores using baseline-adjusted regression, participant-level validation, and leakage and missingness checks.
